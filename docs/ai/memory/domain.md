# Domain Memory

<!-- 2026-04-23 -->
- Obsidian Sync synchronizes plugin `data.json` across a user's devices by default. Per-device state — tokens, local index, pending queue, forensic trails — must live in sibling files written via `app.vault.adapter.write`, NEVER inside `data.json`. The predecessor plugin `obsidian-dropbox-backups` uses a dot-prefixed hidden file (`.__dropbox_backups_token_store__`) for the same reason; Archivist uses `tokens.json`, `index.json`, `pending_changes.json`.
- Dropbox PKCE CLIENT_ID (the Dropbox "App key") is NOT a secret — it is transmitted in the authorization URL the user sees in their browser. Fine as a compile-time constant (`src/config/dropbox.ts`); no env vars, no user config, no Dropbox "App secret" needed for PKCE public clients.
- Dropbox App-Folder mode sandboxes the app to `/Apps/<AppName>/` regardless of what OAuth scope strings are granted. Choosing "Full Dropbox" at app creation bypasses this sandbox and invalidates the entire containment story. ALWAYS choose "App folder" for backup/sync plugins.
- `MarkdownRenderer.render()` invokes all registered Markdown post-processors, including those from co-installed plugins (Dataview, Templater, obsidian-tasks-plugin). Content rendered with MarkdownRenderer CAN execute plugin-registered code. Preview-of-historical-content has the same plugin-interaction surface as live notes — worth disclosing to users as a threat-model boundary.
- Dropbox npm SDK (`dropbox`) last major release in 2022 but actively patched (v10.34.0 at 2025-10-13). Does NOT auto-retry 429 — retry wrapper in the app must honor the `Retry-After` header itself. Pin an exact version in `package.json`; avoid `@latest`.
- `TFile.stat.mtime` is FS-mtime (backed by `DataAdapter.stat()` which proxies Node `fs.stat` on desktop), NOT content-mtime. iCloud / Obsidian Sync preserve mtime on pull in the common case, so mtime often tracks content — but the guarantee is only by convention. When content identity matters, hash is the authority; mtime/size are a cheap dirty-bit hint.
